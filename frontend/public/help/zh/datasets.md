# 数据集管理

## 流程
1. 创建数据集：填写名称与描述，选择格式（COCO / YOLO）。
2. 上传数据：支持图片或 ZIP 压缩包，异步解压入库（Dataset Versions 页可看进度）。
3. 数据集版本：每次上传生成新版本，历史版本保留，可切换。

## 前提条件
- 数据集图片格式支持 jpg / jpeg / png。
- ZIP 内图片在根目录或 images/ 子目录均可。

## 常见问题
- **如何准备标注训练数据？** 在标注工作台完成标注后，通过“导出”生成 YOLO 格式，训练会自动读取。
- **版本号怎么递增？** 每次上传图片自动创建新版本。

## 下一步
标注 → 训练：在**标注**页选择本数据集创建标注项目，或直接在**训练**页选择数据集发起训练。
