# 模型评估

## 流程
1. 创建评估任务：选模型（版本）+ 数据集。
2. 参数可调：置信度阈值（建议 0.25）、最大图片数（0=全部）、任务类型。
3. 评估默认用训练产出的 val 子集；可选任意数据集版本（自动转换 YOLO）。
4. 完成后显示真实指标：mAP50 / Precision / Recall / F1 / 延迟。

## 前提条件
- 模型需有 ONNX 产物。
- 数据集需可解析为 YOLO（平台自动处理）。

## 常见问题
- **为什么 precision 是 0？** 模型未收敛或阈值过高导致预测数少，调低置信度阈值重试。
- **评估数据用哪份？** 默认训练 val 子集，避免数据泄漏。

## 下一步
评估达标后到**模型**页部署，或回到**优化**页继续调优。
