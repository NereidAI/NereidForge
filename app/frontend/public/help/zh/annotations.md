# 标注管理

## 流程
1. 创建标注项目：选择数据集 + 标注任务类型（检测/分割/分类等）。
2. 打开标注工作台：嵌入 Label Studio，逐图标注矩形框、多边形等。
3. 半自动标注：点击“半自动标注”，可选择 ML Backend（模型）对未标注任务预标注。
4. 审核导出：标注完成可导出为 COCO / YOLO / Label Studio JSON / CSV。

## 前提条件
- 需要已上传图片的数据集。
- 半自动标注需要可用的 ML Backend（在 ML Backend 页注册，或使用默认服务）。

## 常见问题
- **预标注没结果？** 确认所选模型的类别与标注配置一致；弱模型置信度低属正常现象。
- **导出到哪？** 导出生成新数据集（YOLO 格式），训练页可直接选择。

## 下一步
导出后到**训练**页创建训练任务，数据闭环自动完成。
