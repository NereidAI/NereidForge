# Third-Party Notices

NereidForge itself is licensed under the Apache License 2.0 (see `LICENSE`).
This file lists the third-party components that the product depends on or
ships inside its own container images, with their licenses. Full license texts
are available from each project; the authoritative list for a given release is
generated by `make license-report` (see `LICENSE-POLICY.md`).

Rules that keep this list meaningful:

- **Default support is permissive only.** Anything shipped, bundled or
  documented as default support uses Apache-2.0 / MIT / MIT-0 / BSD / ISC / PSF / Zlib.
- **Copyleft software is never distributed.** AGPL / GPL / SSPL / BUSL /
  Commons-Clause code, weights and build-time downloads are rejected by
  `scripts/check-license-compliance.sh`.
- **No third-party weights are bundled.** Model weights live in the object
  store or model registry and carry their own license metadata
  (`base_weights.license` in the artifact manifest).
- **Users may bring their own trainer.** A user-supplied image may contain any
  software; NF only orchestrates it and records the declared license. That is a
  compatibility promise, not an inclusion of that software in this product.

Helm charts under `deploy/pre-nereidforge/charts/` declare their dependencies in `Chart.yaml`;
`helm dependency build` resolves permissible dependencies at package time.
Resolved archives are delivery artifacts too, so a disabled condition does not
exempt a copyleft dependency. The NF CVAT chart therefore contains no Grafana
dependency, dashboard provisioning, or Grafana chart archive. Operators may
attach their own Grafana, Loki, or Tempo as L2 services and own their license
obligations. Prometheus scrape paths such as `/metrics` remain protocol-level
compatibility and do not require or distribute Grafana.

## Assets

No fonts, icons or media assets are bundled. `kfp-pipelines/docker/assets/`
no longer contains the proprietary Arial font that older builds copied in;
text rendering uses the fonts already present in the base image.

## Reporting

If you believe a component is listed incorrectly or a copyleft dependency has
slipped in, run `make license-check` and open an issue with the output.
